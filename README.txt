# My Only Love of Life — Zuhaa

A responsive, single-page starfield website with sparkling particle text.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a browser, or use VS Code's Live Server extension.
3. To change the message, edit the heading in `index.html` and the `text` value in `script.js` (`makeTextPoints()`).

No libraries or internet connection are required.
