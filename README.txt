LOVE WEBSITE — QUICK START

1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open it in your browser.
   For the best editing experience, open the folder in Visual Studio Code and use the Live Server extension.

OPTIONAL VIDEO
- Put your own romantic video in this folder.
- Name it exactly: Love me.mp4
- The website will show the video after the visitor clicks “Yes”.
- If the video is missing, a friendly placeholder is shown instead.

FILES
- index.html  = website structure
- style.css   = colors, layout, animations
- script.js   = Yes/No button behavior and floating hearts

This is a static website; no server or paid service is required.
